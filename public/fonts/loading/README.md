## Display font (loader and masthead)

Cinzel Bold (700), Copyright 2020 The Cinzel Project Authors (https://github.com/NDISCOVER/Cinzel). SIL OFL 1.1, bundled in `Cinzel-OFL.txt`. A classical, film-title capital face; not an official Batman font. Lowercase letters are drawn as small capitals, and the gold AI is set 1.16x, so bAIram reads in mixed case. Chosen by Balram 2026-10-15 (option B), replacing Oxanium.

## Reading font (masthead)

Hanken Grotesk, variable 400-500, Copyright 2021 The Hanken Grotesk Project Authors (https://github.com/marcologous/hanken-grotesk). SIL OFL 1.1, bundled in `HankenGrotesk-OFL.txt`. Suggested by taste-skill's type library, trialled side by side, and chosen by Balram 2026-10-17 for all masthead reading text (nav, role line, statement, intro, actions, footer, and the opening's Skip/Replay inside the masthead). Manrope above is still used by the standalone `/prototype/loading` preview only; the masthead page never requests it.
